# Design — apresentações

Sistema visual das orientações da escola, detalhado para execução.
Base: [standards/school/presentations/](../../standards/school/presentations/README.md).

## Composição (tradicional, centralizada)

- Grade simples: título → conteúdo → fonte/nota. Elementos centralizados ou
  alinhados a um eixo consistente; margens generosas em todos os lados.
- Uma mensagem por slide; 3–6 linhas de apoio no máximo (frases curtas, não
  parágrafos).
- Espaço livre é conteúdo: slide "vazio demais" pede corte de texto ou um
  visual funcional — nunca enchimento decorativo.

## Escala tipográfica

- Texto: **20–25 pt**; títulos acima disso; **30 pt = máximo recomendado** para
  texto apresentado; notas/fontes em tamanho menor porém legível à distância.
- Uma família tipográfica (sem serifa para projeção), pesos para hierarquia
  (título > corpo > nota), tamanhos iguais para elementos equivalentes.

## Paleta de 3 cores

1. Fundo neutro (branco/claro) + texto escuro de alto contraste;
2. cor principal nos títulos e cabeçalhos;
3. cor de destaque com moderação (um dado-chave, uma chamada).
- Contraste mínimo confortável para projeção; nunca texto essencial só por cor.

## Visuais funcionais

- Ordem de preferência: diagrama/infográfico que explique > gráfico de dados
  reais > imagem real ilustrativa > nada.
- Gráficos: título que afirma a conclusão, eixos rotulados, sem 3D, fonte dos
  dados no rodapé.
- Imagens: relação direta com o conteúdo; reais (produto, local, captura,
  documento) de preferência; crédito `Fonte da imagem: ...` sempre.

## Antipadrões (nunca)

Setas/caixas/linhas/ícones decorativos, fundos que competem com o texto,
transições/sons gratuitos, clip-art genérico, texto colado de documento,
tabelas densas ilegíveis (resuma ou distribua em slides).
