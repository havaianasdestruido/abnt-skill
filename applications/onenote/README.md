# OneNote — modo orientado (sem skill oficial)

**Quando usar:** notas, organização de material, cadernos.

Não existe skill oficial para OneNote: este módulo **não edita** cadernos.
Entrega estrutura pronta + roteiro de organização.

## O que a abnt-skill entrega

1. **Estrutura de caderno por trabalho:** seções (Fontes, Fichamentos, Rascunho,
   Dúvidas para o orientador, Entrega) com páginas modelo.
2. **Fichamento padrão:** referência completa (NBR 6023) + citação + paráfrase +
   comentário próprio claramente separados (evita plágio acidental).
3. **Mapa do material:** o que vai para o DOCX, o que vira slide, o que é
   descarte — com os arquivos de origem listados.

Indique o passo manual ("crie a seção X e cole este conteúdo") — nunca afirme
ter alterado um caderno.
