# Outlook — modo orientado (sem skill oficial)

**Quando usar:** e-mails, calendário, reuniões.

Não existe skill oficial para Outlook: este módulo **não manipula** caixa de
entrada, agenda ou reuniões. Entrega conteúdo pronto + roteiro.

## O que a abnt-skill entrega

1. **E-mails acadêmicos/profissionais:** assunto objetivo, saudação, contexto em
   2–3 frases, pedido/ponto claro, fechamento com identificação (nome, curso,
   matrícula quando aplicável). Tom formal e conciso.
2. **Reuniões/orientações:** pauta com objetivo, tópicos cronometrados,
   material anexo listado, combinados registrados em ata-resumo após.
3. **Envio de trabalhos:** texto de apresentação + checklist de anexos
   (arquivo final + fontes, nomeação `Sobrenome_Tema_vFinal.ext`).

Sempre indique o passo manual ("cole no Outlook", "anexe o arquivo X") — nunca
afirme ter enviado ou agendado algo.
