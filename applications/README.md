# applications/ — aplicativos

Decisão de **quando** usar cada aplicativo e **o que** pedir à camada
operacional (skills oficiais). Estes módulos orientam; quem manipula arquivos
DOCX/PDF/PPTX/XLSX são as skills oficiais (ver [office-oficial.md](office-oficial.md)).

| Módulo | Quando usar |
|---|---|
| [word/](word/README.md) | trabalhos, relatórios, artigos, textos acadêmicos, documentos formatados |
| [powerpoint/](powerpoint/README.md) | apresentações, seminários, aulas, slides |
| [excel/](excel/README.md) | dados, tabelas, cálculos, gráficos, análise, planilhas |
| [outlook/](outlook/README.md) | e-mails, calendário, reuniões (modo orientado) |
| [onenote/](onenote/README.md) | notas, cadernos, organização de material (modo orientado) |
| [access/](access/README.md) | bancos de dados, consultas, formulários, relatórios (modo orientado) |

> Outlook, OneNote e Access **não** possuem skill oficial (só existem `docx`,
> `pdf`, `pptx`, `xlsx`): os módulos correspondentes entregam roteiro + conteúdo
> pronto, sem manipulação direta de arquivos.
