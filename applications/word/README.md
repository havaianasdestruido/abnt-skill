# Word — documentos (via skill oficial `docx`)

**Quando usar:** trabalhos, relatórios, documentos, artigos, textos acadêmicos,
documentos formatados.

## O que a abnt-skill decide (antes de delegar)

1. Tipo de documento (TCC, relatório, artigo, projeto) e estrutura de seções
   ([standards/abnt/formatacao.md](../../standards/abnt/formatacao.md),
   [artigos-projetos.md](../../standards/abnt/artigos-projetos.md)).
2. Estilos: Normal 12 pt justificado 1,5; títulos por nível; citações longas
   (fonte menor, simples); referências (simples + espaço entre elas).
3. Página A4, margens 3/2/3/2, paginação da parte textual em diante.
4. Sumário espelhando numeração (NBR 6024/6027), resumo 150–500 palavras (NBR 6028).
5. Design de texto corrido: [design/documents/](../../design/documents/README.md).

## O que delegar à skill oficial `docx`

Criação/edição do `.docx`: estilos, sumário automático, cabeçalhos/rodapés,
numeração de páginas, tabelas, imagens com título+fonte, controle de alterações
quando revisão. Transmita as especificações acima como requisitos fechados.

## Checklist específico

- [ ] Formatação NBR 14724 aplicada (margens, fonte 12, 1,5, paginação)
- [ ] Citações (NBR 10520) e referências (NBR 6023) consistentes entre si
- [ ] Toda figura/tabela citada no texto, próxima ao trecho, com título e fonte
- [ ] Checklist geral: [assets/checklists/entrega.md](../../assets/checklists/entrega.md)
