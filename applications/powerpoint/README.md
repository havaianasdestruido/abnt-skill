# PowerPoint — apresentações (via skill oficial `pptx`)

**Quando usar:** apresentações, seminários, aulas, slides, apresentações
acadêmicas.

## O que a abnt-skill decide (antes de delegar)

1. Roteiro: mensagem por slide, ≈10 slides (≈20 min), podendo ir a ≈20.
2. Tipografia: texto 20–25 pt, **máx. 30 pt**; nunca reduzir para caber texto —
   cortar/reorganizar conteúdo ([standards/school/presentations/](../../standards/school/presentations/README.md)).
3. Layout: composição tradicional centralizada, hierarquia clara, respiro;
   sem elementos decorativos sem função.
4. Paleta de no máx. 3 cores (neutro + títulos + destaque moderado).
5. Visuais: infográfico/diagramas/gráficos/imagens reais com relação direta;
   cada um com `Fonte:` discreta e legível.
6. Conteúdo citado segue ABNT (citações/referências/fontes); estética não é
   regida por NBR.
7. Design: [design/presentations/](../../design/presentations/README.md).

## O que delegar à skill oficial `pptx`

Criação/edição do `.pptx`: slide mestre e layouts, caixas de texto nos tamanhos
definidos, inserção de imagens/gráficos/tabelas, notas do orador (roteiro de
fala), ordem de leitura. Transmita roteiro + especificações como requisitos.

## Checklist específico

- [ ] 20–25 pt no texto, nada acima de 30 pt; nada ilegível
- [ ] Um fluxo narrativo claro (início → desenvolvimento → fechamento)
- [ ] Toda imagem/dado externo com fonte; referências finais quando apropriado
