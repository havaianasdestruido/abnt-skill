# Fluxo: dados → planilha organizada

`/abnt Organize esta planilha seguindo as orientações da escola.` ·
`/abnt Organize estes dados em uma planilha.`

1. **Auditar entrada** (CSV/XLSX solto/sujo): separador, codificação,
   cabeçalhos, tipos, sujeira, totais.
2. **Normalizar** (skill `xlsx`): tabela-fato limpa (cabeçalho único, sem
   mesclagem), abas por função (Dados, Cálculos, Gráficos, Sobre/Fontes).
3. **Calcular**: fórmulas necessárias com conferência contra a fonte;
   formatação de números/datas consistente.
4. **Visualizar quando necessário**: um gráfico por mensagem, eixos rotulados,
   sem distorção, com `Fonte:` dos dados.
5. **Aplicar escola**: clareza, atribuição de origem, impressão configurada.
6. **Validar**: [assets/checklists/entrega.md](../assets/checklists/entrega.md).
