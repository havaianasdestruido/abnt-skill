# Fluxo: documento → apresentação

`/abnt Transforme este relatório em uma apresentação.` ·
`/abnt Faça um PowerPoint baseado neste documento.`

1. **Ler estrutura** (skill `docx` ou `pdf`): títulos, tabelas, figuras,
   conclusões; a hierarquia de títulos sugere o roteiro.
2. **Comprimir, não colar**: cada seção vira 1–2 slides de mensagem + apoio;
   texto corrido fica nas notas do orador, nunca no slide.
3. **Converter evidências**: tabelas densas → gráfico ou quadro-resumo;
   conceitos → diagrama; manter `Fonte:` em tudo reaproveitado.
4. **Aplicar escola + design** (10-20-30 flexível, 20–25 pt, 3 cores,
   centralizado) e ABNT no conteúdo citado.
5. **Produzir PPTX** (skill `pptx`) + roteiro de fala nas notas.
6. **Validar**: [assets/checklists/entrega.md](../assets/checklists/entrega.md).
