# Fluxo: trabalho acadêmico ABNT do zero

`/abnt Faça um trabalho acadêmico seguindo ABNT.`

1. **Definir gênero e tema**: TCC, relatório, artigo ou projeto; tese/objetivo;
   material de partida (ou pesquisa a fazer — registrar todas as fontes).
2. **Estruturar** (NBR 14724 / 6022 / 15287 conforme o gênero): capa,
   pré-textuais, textuais, pós-textuais.
3. **Redigir com normas**: NBR 10520 (citações), 6023 (referências), 6024
   (numeração), 6027 (sumário), 6028 (resumo) — ver
   [standards/abnt/](../standards/abnt/README.md).
4. **Aplicar escola**: documentos claros, figuras/tabelas com título + fonte.
5. **Produzir DOCX** (skill `docx`) + opcional PDF final (skill `pdf`).
6. **Validar**: [assets/checklists/entrega.md](../assets/checklists/entrega.md).
