# Fluxo: PDF → trabalho DOCX

`/abnt Crie um documento baseado neste PDF.` · `/abnt Faça um trabalho baseado nesse PDF.`

1. **Extrair** (skill `pdf`): texto/tabelas do PDF; OCR se digitalizado.
   Registrar origem (documento, páginas, URL).
2. **Interpretar**: tese central, argumentos, dados aproveitáveis; separar fato
   citado de interpretação própria.
3. **Estruturar**: elementos ABNT do gênero pedido (capa → … → referências);
   ver [standards/abnt/formatacao.md](../standards/abnt/formatacao.md).
4. **Redigir com normas**: citações NBR 10520, referências NBR 6023, numeração
   NBR 6024, sumário NBR 6027, resumo NBR 6028 quando aplicável.
5. **Aplicar escola**: clareza, tabelas/figuras com título + fonte, atribuições.
6. **Produzir DOCX** (skill `docx`) conforme
   [applications/word/](../applications/word/README.md) e
   [design/documents/](../design/documents/README.md).
7. **Validar**: [assets/checklists/entrega.md](../assets/checklists/entrega.md).
