# Fluxo: PDF → apresentação PPTX

`/abnt Faça um PowerPoint baseado nesse PDF.`

1. **Extrair** (skill `pdf`): conteúdo + dados; registrar origem.
2. **Interpretar**: identificar apenas as informações relevantes para ≈10
   slides (≈20 min); descartar o resto (apresentação ≠ resumo integral).
3. **Roteirizar**: mensagem por slide (início → desenvolvimento → fechamento);
   dados que viram gráfico, conceitos que viram diagrama.
4. **Aplicar escola + design**: 20–25 pt (máx. 30), composição centralizada,
   paleta de 3 cores, visuais funcionais, zero enchimento.
5. **Conteúdo citado**: citações/referências/fontes no padrão ABNT; cada
   imagem/dado com `Fonte:`.
6. **Produzir PPTX** (skill `pptx`) conforme
   [applications/powerpoint/](../applications/powerpoint/README.md); roteiro de
   fala nas notas do orador.
7. **Validar**: [assets/checklists/entrega.md](../assets/checklists/entrega.md).
