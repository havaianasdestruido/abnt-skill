# Orientações da escola — apresentações

Referência flexível, não norma rígida. A ABNT rege o conteúdo citado
(citações, referências, fontes); o visual segue estas orientações + a camada
[design](../../../design/README.md).

## Regra 10-20-30 (flexível)

- **≈10 slides** — referência, não limite. Uma aula/apresentação pode chegar a
  **≈20 slides** quando necessário.
- **≈20 minutos** de apresentação.
- **30 pt = tamanho máximo recomendado** para o texto apresentado.

## Tipografia (não confundir com fontes bibliográficas)

- Faixa desejável do texto: **20–25 pt**; máximo recomendado: **30 pt**.
- Tamanhos consistentes entre elementos equivalentes.
- **Nunca reduza a tipografia para caber informação excessiva**: se há texto
  demais, reduza ou reorganize o conteúdo.

## Layout

- Estética simples, limpa, semelhante à composição tradicional de PowerPoint:
  conteúdo **centralizado**, alinhamento consistente, hierarquia clara, bastante
  espaço livre, composição equilibrada.
- Evite informações aleatórias nas laterais; nada de assimetria apenas para
  parecer "moderno".

## Proibição de elementos inventados

Não adicione elementos sem função. Evite automaticamente: setas decorativas,
caixas aleatórias, linhas decorativas, ícones/forma sem função, textos
desnecessários, informações/estatísticas/exemplos inventados (e jamais apresente
exemplo inventado como fato), visuais apenas para preencher espaço. Se não há
necessidade, não coloque.

## Elementos visuais

- Priorize: **infográfico, diagramas, gráficos em geral e imagens ilustrativas**.
- Imagens com **relação direta** com o conteúdo.
- Prefira **imagens reais** quando apropriado: produto, marca, logotipo,
  equipamento, local, fotografia, captura de tela, objeto real, material
  documental. Evite imagens geradas por IA quando existir imagem real adequada.

## Paleta

No máximo **3 cores principais**: (1) branco/neutro, (2) cor principal para
títulos, (3) cor de destaque — esta com moderação. Nada de múltiplas cores
decorativas.

## Fontes das informações (origem, não tipografia)

- Todo material externo (texto, dados, estatísticas, imagens, gráficos, tabelas,
  fotografias, logotipos, conceitos, sites, documentos) possui origem
  identificável, com atribuições discretas mas legíveis e referências completas
  no final quando apropriado.
- Exemplos: `Fonte: IBGE.` · `Fonte: Ministério da Saúde.` ·
  `Fonte: Nome do site — URL` · `Fonte da imagem: Wikimedia Commons.`
- Não remover créditos existentes; respeitar licenças e direitos de uso.
