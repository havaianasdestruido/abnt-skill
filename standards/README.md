# standards/ — normas e orientações

Duas camadas distintas, aplicadas simultaneamente:

- **[abnt/](abnt/README.md)** — normas técnicas ABNT/NBR pesquisadas em guias
  públicos (sempre com fonte citada; sem números ou regras inventados).
- **[school/](school/README.md)** — orientações flexíveis da escola
  (documentos e apresentações).

Regra de precedência (ver `SKILL.md` §2): documentos formais → ABNT prevalece;
apresentações → escola/design no visual, ABNT no conteúdo citado. Conflitos são
sempre comunicados ao usuário.
