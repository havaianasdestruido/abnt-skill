# standards/abnt/ — normas ABNT pesquisadas

A Associação Brasileira de Normas Técnicas (ABNT) é o órgão responsável pela
normalização técnica no Brasil, incluindo as normas de trabalhos acadêmicos.

> **Aviso de honestidade:** os textos integrais das NBRs são protegidos por
> direitos autorais e não estão reproduzidos aqui. Estes módulos resumem regras
> a partir de guias públicos, **sempre citados**. Nada aqui foi inventado: onde
> as fontes divergem (p.ex. ano de edição) ou calam, o módulo diz explicitamente
> para confirmar na NBR vigente ou no manual da instituição.
