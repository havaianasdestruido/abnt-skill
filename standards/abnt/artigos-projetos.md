# NBR 6022 e NBR 15287 — artigos e projetos de pesquisa

## NBR 6022:2018 — artigo científico

- Estrutura **reduzida** em relação ao TCC: sem os elementos pré-textuais de
  monografia (sem capa/folha de rosto/sumário).
- Elementos usuais (conforme guias): título, autoria, resumo + palavras-chave
  (100 a 250 palavras, NBR 6028), texto (introdução, desenvolvimento,
  conclusão), referências.
- Formatação interna (margens, fonte, citações, referências) segue as mesmas
  NBRs 14724/10520/6023 salvo norma específica do periódico — o periódico
  prevalece.

## NBR 15287 — projeto de pesquisa

- Documento que **antecede** o trabalho final, com estrutura própria
  (tema, problema, objetivos, justificativa, referencial, metodologia,
  cronograma, recursos, referências — confirmar nomenclatura no manual
  institucional).
- A skill trata projetos com os mesmos padrões de formatação/citação/referência
  das NBRs acima.
