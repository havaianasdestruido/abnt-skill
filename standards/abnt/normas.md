# Catálogo de NBRs para trabalhos acadêmicos

Números, títulos e escopos confirmados nas fontes (ver README desta pasta).
Anos de edição seguem o citado por cada fonte; **sempre confirme a edição
vigente** antes de entregar um trabalho formal.

| NBR | Título/escopo | Aplica-se a |
|---|---|---|
| NBR 14724 (:2024 na fonte consultada) | Apresentação de trabalhos acadêmicos: estrutura geral, formato, margens, fonte, espaçamento, paginação | TCC, monografia, dissertação, tese |
| NBR 10520 (:2023) | Citações em documentos: diretas, indiretas, citação de citação (apud) | todos os trabalhos |
| NBR 6023 (:2018 em uma fonte; outra cita :2025 — **verificar edição vigente**) | Elaboração de referências | todos os trabalhos |
| NBR 6024 (:2012) | Numeração progressiva das seções | todos os trabalhos |
| NBR 6027 (:2012) | Sumário: apresentação | todos os trabalhos |
| NBR 6028 (:2021) | Resumo, resenha e recensão: redação e extensão | TCC, dissertação, tese |
| NBR 6022 (:2018) | Artigo em publicação científica periódica | artigos científicos |
| NBR 15287 | Projeto de pesquisa: apresentação | anteprojeto/projeto de TCC |

Tipos de trabalho (conforme guia CAPES/Unesp): artigo científico, TCC
(graduação/especialização), TGI, TCR, dissertação, tese — todos "publicações
monográficas realizadas sob coordenação de um orientador", distinguindo-se pelo
grau de profundidade.

> Não cite edições/anos diferentes destes sem verificar. Nunca apresente como
> "regra ABNT" algo que seja apenas convenção de manual institucional — os
> módulos abaixo marcam essas distinções.
