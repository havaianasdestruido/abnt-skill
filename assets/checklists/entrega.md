# Checklist final de entrega

Aplicar a **todo** artefato antes de entregar. Marcar `[x]` mentalmente item a
item; nada pode sair com item obrigatório pendente.

## Identidade e roteamento

- [ ] Experiência via `/abnt`; usuário não precisou escolher módulo interno
- [ ] Aplicativo correto para o objetivo (Word/PowerPoint/Excel ou orientado)

## ABNT (documentos formais)

- [ ] Estrutura do gênero correta (14724 / 6022 / 15287)
- [ ] Margens 3/2/3/2, A4, fonte 12, 1,5 (exceções em menor/simples)
- [ ] Paginação contada da rosto, figurando da parte textual, superior direita
- [ ] Citações (10520) × referências (6023): toda citação referenciada e vice-versa
- [ ] Numeração progressiva sem sinal entre indicativo e título (6024)
- [ ] Sumário = último pré-textual, espelhando texto (6027)
- [ ] Resumo 150–500 palavras, parágrafo único, 3–5 palavras-chave (6028)

## Escola — apresentações

- [ ] ≈10 slides (≈20 min); até ≈20 se necessário; 10-20-30 como referência
- [ ] Texto 20–25 pt; **nada acima de 30 pt**; consistência entre equivalentes
- [ ] Nenhum texto reduzido para caber excesso (conteúdo foi cortado/reorganizado)
- [ ] Composição centralizada, hierarquia clara, respiro; sem assimetria gratuita

## Escola — geral

- [ ] Paleta de no máximo 3 cores; destaque com moderação
- [ ] Zero elementos inventados/decorativos sem função; zero fatos inventados
- [ ] Visuais funcionais (infográfico/diagrama/gráfico/imagem real pertinente)
- [ ] Toda origem externa com `Fonte:` discreta e legível; referências finais
      quando apropriado; créditos existentes preservados; licenças respeitadas

## Operação

- [ ] Manipulação de DOCX/PDF/PPTX/XLSX feita pela skill oficial correspondente
- [ ] Se alguma skill oficial indisponível: modo orientado declarado, sem
      simular manipulação de arquivo
