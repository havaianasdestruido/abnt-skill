# CSV — dados tabulares brutos

Sem skill oficial dedicada: **matéria-prima** a normalizar em XLSX (skill `xlsx`).

## Como tratar

- **Entrada:** detectar separador, codificação e cabeçalho; checar linhas
  malformadas, cabeçalhos deslocados e sujeira; tipos (número/data/texto)
  definidos antes de qualquer cálculo.
- Nunca entregar CSV "organizado" como artefato final de um trabalho que pede
  planilha: o destino é **XLSX** formatado, com fonte dos dados.
- Registrar transformações feitas (o que foi removido/corrigido) na aba
  Sobre/Fontes.
