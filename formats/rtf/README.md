# RTF — texto formatado genérico

Sem skill oficial dedicada: tratado como **formato genérico de intercâmbio**,
sem abstração específica de aplicativo.

## Como tratar

- **Entrada:** ler conteúdo + formatação básica; converter para DOCX (via skill
  `docx`) quando o destino for um trabalho formal ABNT.
- **Saída:** somente quando solicitada interoperabilidade máxima (sistemas
  antigos/diversos); caso contrário prefira DOCX.
- Não prometer fidelidade pixel-perfect: RTF preserva formatação essencial,
  não layouts complexos.
