# XLSX — planilhas

Operação pela skill oficial **`xlsx`**.

## Como tratar

- Formato de **trabalho com dados**: fórmulas vivas, validação, gráficos.
- **Entrada:** auditar antes de usar (cabeçalhos, tipos, totais, sujeira);
  dados bagunçados passam por normalização antes de qualquer análise.
- CSV é matéria-prima, XLSX é o artefato organizado (ver
  [../csv/README.md](../csv/README.md) e
  [workflows/dados-para-planilha.md](../../workflows/dados-para-planilha.md)).
- Entregas impressas/PDF derivam do XLSX final, com fonte dos dados.
