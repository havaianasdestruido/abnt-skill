# PDF — leitura, extração e saída final

Operação pela skill oficial **`pdf`**.

## Como tratar

- **Entrada (fonte de conteúdo):** extrair texto/tabelas; digitalizados pedem
  OCR; formulários têm fluxo próprio na skill oficial. Sempre registrar
  `Fonte: <documento/página/URL>` do que for aproveitado.
- **Atenção:** PDF preserva layout, não estrutura — títulos, tabelas e notas
  exigem reinterpretação antes de virar DOCX/PPTX/XLSX (ver
  [workflows/](../../workflows/README.md)).
- **Saída:** PDF é o formato de entrega não-editável (envio/entrega final);
  gere a partir do DOCX/PPTX/XLSX final, nunca como rascunho de trabalho.

## Limites

- PDFs protegidos/criptografados podem exigir credenciais; respeite-as.
- Qualidade de extração varia com o layout original — confira números e
  citações contra o original antes de entregar.
