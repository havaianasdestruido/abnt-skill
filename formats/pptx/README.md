# PPTX — apresentações

Operação pela skill oficial **`pptx`**.

## Como tratar

- Formato de **apresentação editável**; slide mestre e layouts garantem
  consistência (definidos a partir da camada design + escola).
- **Entrada:** ao reaproveitar um PPTX existente, extrair inventário de texto e
  respeitar/adequar o mestre; nunca duplicar estilos conflitantes.
- **Modelos (.potx):** modelo institucional prevalece sobre defaults.
- Notas do orador carregam o roteiro de fala (≈20 min); slides carregam
  mensagem + apoio visual, nunca o discurso integral.
