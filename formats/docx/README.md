# DOCX — documentos editáveis

Operação pela skill oficial **`docx`**.

## Como tratar

- Formato de **trabalho e entrega editável** para Word; preserva estilos,
  sumário, numeração e revisões.
- **Entrada:** ler estrutura (estilos de título, tabelas, imagens) antes de
  converter para slides ou reorganizar — a estrutura de títulos vira o roteiro.
- **Modelos (.dotx):** quando a instituição fornecer modelo, ele prevalece
  sobre defaults desta skill (registre a precedência ao usuário).
- Conversões: ver [workflows/documento-para-apresentacao.md](../../workflows/documento-para-apresentacao.md).
